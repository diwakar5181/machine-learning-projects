
# Project Name: Support Vector Regression

> Encode dataset, Implement Support Vector Regression, and tune Hyperparameters to improve accuracy

## Requirements
* Python 3.14
* Seaborn

## 🎯 Why I Built This
I built this project to understand Support Vector Regression, dataset Encoding and Hyperparameter tuning

## ✨ Key Features
- Load dataset from Seaborn
- Split data into train and test datasets
- Apply encoding after train, test split to prevent data leakage
- Create a Support Vector Regression model and fit training data
- Do model predictions on test data
- print r2_score and mean_absolute_error
- Implement GridSearchCV with hyperparameters for best fit and rerun fit and predict
- print r2_score and mean_absolute_error
