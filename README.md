# Machine Learning Projects

A curated collection of hands-on machine-learning projects that demonstrates the practical application of foundational algorithms and data-science workflows. Each project is designed as a focused exploration of a specific technique, with an emphasis on clear implementation, model evaluation, and interpretable results.

## Repository Overview

The projects in this repository use Python and common machine-learning libraries to work through key stages of an applied ML workflow:

- Data preparation and feature scaling
- Model development and training
- Model selection and performance evaluation
- Dimensionality reduction and visualization
- Interpretation of predictions and clustering results

## Topics Covered

| Area | Projects and techniques |
| --- | --- |
| Regression | Linear regression and support vector regression |
| Classification | Logistic regression, decision trees, random forests, and support vector machines |
| Ensemble learning | AdaBoost, gradient boosting, and XGBoost |
| Unsupervised learning | K-means and hierarchical clustering |
| Dimensionality reduction | Principal component analysis (PCA) |

## Technologies

The projects primarily use Python with pandas, NumPy, Matplotlib, scikit-learn, and related libraries. Individual project requirements are documented locally to keep environments lightweight and reproducible.

## Purpose

This repository serves as a practical learning portfolio for strengthening core machine-learning knowledge through implementation and experimentation. It reflects an ongoing focus on building a sound understanding of algorithms, their assumptions, and how to evaluate them in practice.
